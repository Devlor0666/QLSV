# Quản lý sinh viên

## 📌 Giới thiệu

Đây là project quản lý sinh viên được xây dựng bằng JavaScript.
Project cho phép người dùng xem, thêm, sửa, xóa và tìm kiếm thông tin sinh viên.

## 🚀 Chức năng

- Hiển thị danh sách sinh viên
- Thêm sinh viên
- Sửa thông tin sinh viên
- Xóa sinh viên
- Tìm kiếm sinh viên
- Lọc sinh viên
- Phân trang danh sách
- Hiển thị thông báo lỗi

## 🛠️ Công nghệ sử dụng

- HTML
- CSS
- JavaScript
- ES Modules
- JSON
